# Estructura del proyecto "curso-js"

* **CSS:** Contiene los archivos de los estilos (Incluye los del sitio Bulma CSS y estilos personalizados por nosotros mismos)
* **images:** Contiene las imagenes y recursos gráficos usados para las actividades que se hicieron
* **Archivos JS y HTML** Contiene los laboratorios de maipulación del DOM, eventos, objetos, cadenas, desestructuración y formularios

# Tecnologías a usar 

* HTML5 / CSS3
* JavaScript
* Bulma CSS 
* Git y GitHub para el control de versiones

# Uso del repositorio

* Crear o clonar el repositorio desde GitHub
* En la terminal del proyecto, realizar commits dependiendo de los cambios que vayamos haciendo, de esa manera ir registrando nuestros avances hasta completar toda la actividad
* Usar `git clone` para clonar el repositorio
* Usar `git pull` para sincronizar y traer los cambios hechos en otro equipo
